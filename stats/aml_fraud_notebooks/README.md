# AML + Fraud Analytics notebook curriculum

Framework: *Fraud Analytics* (Baesens et al.) = process; *AML Transaction Monitoring Systems Implementation* (Chau & van Dijck Nemcsik) = AML concepts; *Practical Statistics for Data Scientists* = statistics.

Run in order (`python run_all.py`, ~10 min; data is synthetic and regenerated by `amlkit.ensure_data()`):

| Notebook | Content |
|---|---|
| 00–02 | Framework, data quality & sampling, EDA/cleaning/transformation |
| 03 | Descriptive analytics applied to AML (peer groups, break points, clustering, isolation forest) |
| **03a–03d** | **Concept-by-concept deep-dives of Fraud Analytics chapters 2, 3, 4, 5** (explanation + book examples reproduced + lab code) |
| 04–05 | Chau's 11-step threshold tuning and its statistical critique |
| 06–07 | Predictive and social-network analytics applied to the lab bank |
| 08 | Evaluation, deployment, monitoring |

`data/_hidden_ground_truth.csv` is an oracle used only to grade methods, never as a model input. `03a` needs `01`/`02` outputs, so run in order.

## Environment
```
bash setup_env.sh        # macOS / Linux          (Windows: setup_env.bat)
source .venv/bin/activate   # Windows: .venv\Scripts\activate
jupyter lab              # pick kernel "Python (aml-fraud venv)"
```
Tested with Python 3.12 (numpy 2.4-2.5, pandas 3.0, scikit-learn 1.8-1.9, scipy 1.17-1.18, statsmodels 0.15, networkx 3.6). The `.venv` folder itself is not portable and is not included in the zip.
